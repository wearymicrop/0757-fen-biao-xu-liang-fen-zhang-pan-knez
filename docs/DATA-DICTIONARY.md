# 数据字典

| 输入表 | 关键字段 | 约束 |
|---|---|---|
| config | site、main_meter、meters、start、end、rate_cents_per_kw | 总表号单列，分表用字符串列表。窗口端点含时区，费率是人民币分每千瓦 |
| gateways | gateway、offset_seconds | 时钟偏差按秒，正值代表报时比实际偏晚，校时时减去该偏差 |
| readings | gateway、meter、at、value、unit | 时间为 5 分钟采样区间起点。支持 W、kW，换算后须是整瓦。千位分组可用，哨兵单独隔离 |
| mappings | meter、account、version、start、end | 映射左右为生效始末，左闭右开。需同一版本完整覆盖一个 15 分钟窗 |

时间戳按实际瞬时转为 UTC，界面以 UTC+08 显示窗口。计量批次左右端点均落在 15 分钟格点，起始纳入、结束排除。取样纠偏后须落在 5 分钟格点。同表同刻同值保留首条并登记重传。同表同刻异值全部隔离。可接受的乱序样本仍计入。窗口内总表及各登记分表均需要三个格点，缺失则整个窗口退出找峰。

共同峰取所有完整窗口中园区总表三点平均功率最高的一窗，相同取最早一窗。分表均取此窗的平均功率，独立峰留作比对。映射冲突分表及总分表差额计入未分配量。总表低于分表合计时暂停出账。`w_sum` 是三点瓦数之和，平均瓦值为 `w_sum / 3`，界面千瓦显示至小数三位，精确金额仍使用未舍入的三点和。

按费率计算账单总额，先按精确分数把各账户金额取整，再按最大余数补齐至整分总额。未分配量单列，金额可复核。只提供同周期规则和账单草案，单批最多 15,000 个表号与窗口组合。
